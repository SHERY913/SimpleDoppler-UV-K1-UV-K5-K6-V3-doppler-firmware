## 五、读代码时的三个坑（血换来的）

- **「编译通过 + 自检绿」≠「能用」**。没上机的一切都只是"应该"。
- **注释说它做了 ≠ 代码真做了**。历史上半数 P0 都是这个形状：注释写"回读比对""心跳""峰值保持"，
  代码里只有一行似是而非的东西。核注释的唯一办法是拿它的说法对一遍代码或反汇编。
- **两端各自修过的 bug 只算修了一半**。App / PC / 固件三端都出现过"一端修了另两端漏着"，
  症状是"同一颗星两台机器结果不一样"，谁也复现不了。
