## 一、项目是什么

给 **泉盛 UV-K1 / UV-K5 V3**（PY32F071，Cortex-M0+）魔改的 F4HWN v6.3.0 固件，加了**卫星多普勒自动跟踪页**，另配 PC 工具（算过境、写表）和安卓 App（解算 + 指向 + 实时控频 + 录音）。

**两套逻辑**，这是理解整个项目的关键：

| | 第一套（电台自算） | 第二套（手机推） |
|---|---|---|
| 数据来源 | PC/手机提前写好并烧进外置 flash 的过境表 | 手机 5 Hz 推 `0x076C` 帧 |
| 电台干什么 | 读表 → 自己插值 → 自己写 PLL | 只显示 + 执行，频率、上行、多普勒全来自手机 |
| 进入方式 | F+0 进页，M 开始 | 手机接管（`0x0768=1`）后自动进页 |
| 屏幕页 | READY/RUN/DONE… | **复用 RUN 页**（page 1），不另画 |
| 归属 | `phase` = READY/RUN/DONE | `phase` = `DPH_EXT` |

### 3.4 第二套逻辑（DPH_EXT）的完整链路

```
手机 5 Hz 推 0x076C ──→ DOPPLER_ExtPush()
                        ├─ 解析 rx10/tx10/dopp/dist/remain/el/rate/progress/flags/name
                        ├─ 固件自己 BK4819_SetFrequency(rx10*10)（发射时不写，防拽回接收频率）
                        ├─ gTxVfo->pTX->Frequency = tx10*10（PTT 用的就是它）
                        ├─ 心跳 ext_ctrl_tick（15 秒不来就自动交还 + 双 beep）
                        └─ 首次进页时 DPH_AudioOpen()（开静噪/喇叭/音频路径）
                        └─ 回 0x076D + state
```

- **接管时自动进页**：`DOPPLER_Tick10ms()` 开头，`ext_ctrl && ext_page_on && phase == DPH_OFF` → `DOPPLER_Start()` + `DPH_AudioOpen()` + `phase = DPH_EXT`。这条是为了解决「手机显示接管了，电台屏幕毫无变化」。
- **页面复用**：`UI_DisplayDoppler()` 里 `case DPH_EXT: DPH_DrawPage(1)`，即操作员自己排的 RUN 页，一个像素都不改，变的只是每个占位符的来源（`DPH_Expand` 里的 EXT 分支）。
- **EXT 只拦截** `$F $Y $E $G $H $P $L $C $S $N $T $U $M $R $A $B $W $K $X $I $O`；`$Z`（亚音）、`$Q`（功率）、`$D`（信号表）**照旧由固件算**。`$J` = APP 角标（接管中显示 `APP`，M 键被拒时闪 `LOCKED` 2 秒）。
- **PTT**：`DOPPLER_ProcessKeys()` 里 EXT 阶段无条件放行（第一套仍要求 `cur.up10 != 0`）。
- **看门狗**：`DPH_EXT_TIMEOUT_TICKS 1500`（15 秒），断线自动交还并 `BEEP_500HZ_60MS_DOUBLE_BEEP`。
- **交还不跳变**：`DOPPLER_SetExtControl(false)` 会先恢复 `gRxVfo` 频率，RUN 中则按 elapsed 算回当前偏移再 `DPH_Tune()`，不会从卫星频率直接跳回标称。

### 3.5 新增串口命令（第二套逻辑）

| cmd | 方向 | payload | 回包 | 说明 |
|---|---|---|---|---|
| `0x0768` | 发 | `mode(u8)` 1=接管 0=交还 | **无回包** | 外部控频开关 |
| `0x076A` | 发 | 空 | `0x076B` + `proto(1)+state(1)+phase(1)`（共 7 B） | 固件自检，用来分辨「刷没刷上」 |
| `0x076C` | 发 | 见下 | `0x076D` + `state(1)`（5 B） | 推一整帧显示 + 频率数据，同时也是心跳 |
| `0x076E` | 发 | `on(u8)` | `0x076F` + `state(1)` | 允许/禁止固件切到手机推送页 |

**`0x076C` 载荷（≥28 字节，按 LE）**

```
[0:4]   rx10      u32   接收频率，单位 10 Hz
[4:8]   tx10      u32   上行频率，单位 10 Hz（0 = 未知）
[8:10]  dopp      i16   多普勒偏移 Hz
[10:12] dist      u16   斜距 km
[12:14] remain    i16   距 LOS 秒（-1 = 未过境）
[14:16] el01      i16   仰角 ×10
[16:18] rate01    i16   变化率 ×100（km/s）
[18]    progress  u8    进度 0~100
[19]    flags     u8    预留
[20]    nameLen   u8    0~8
[21:]   name      bytes  卫星名，不足补 0
```

> 载荷不足 28 字节固件**整帧丢弃**。名字短的星（`"ISS"` 只有 3 字节）算出来才 24，所以 App 侧显式补到 28。

**状态位 `state`（`DOPPLER_ExtState()`）**

| 位 | 含义 |
|---|---|
| 0x01 | App 正在接管 |
| 0x02 | 正在过境（第一套 RUN） |
| 0x04 | 过境表已加载 |
| 0x08 | 武装倒计时中 |
| 0x10 | 新页开关已打开 |
| 0x20 | PTT 按着（`tx_hold`） |
| 0x40 | 芯片正在发射（`gCurrentFunction == FUNCTION_TRANSMIT`） |

## 四、串口协议

### 4.1 物理层

| 项 | 值 |
|---|---|
| 波特率 | **38400**，8N1 |
| USB | CDC-ACM，VID `0x36B7`，PID `0xFFFF` |
| Windows 设备名 | `USB 串行设备 (COM7)`；`BusReportedDeviceDesc` = `PUYA CDC DEMO`（PUYA＝普冉，就是这颗 MCU 的厂商） |

安卓必须手动注册 VID：

```kotlin
prober.table.addProduct(0x36B7, 0xFFFF, CdcAcmSerialDriver::class.java)
```

### 4.2 帧格式（踩过坑，照抄 `RadioLink.kt:22-61`）

```
AB CD | len(2, LE) | (msg ‖ crc16(msg)(2, LE)) 逐字节 XOR MASK | DC BA

msg  = cmd(2, LE) + payloadLen(2, LE) + payload
crc16 = CRC-16/XMODEM（初值 0，poly 0x1021，MSB first），对**未混淆**的 msg 计算
msg 长度为奇数 → 先补一个 0x00 再算 CRC，长度字段也跟着 +1

MASK（16 字节循环）：
16 6C 14 E6 2E 91 0D 40 21 35 D5 40 13 03 E9 80
```

顺序：**先算 CRC → 再把 `msg + crc` 一起 `^= MASK[i % 16]`**。

> 曾经写的探针脚本漏了 CRC，固件校验不过就静默丢弃，看起来像「电台完全不回包」，白查了半天设备身份。写新工具时先拿 `0x076A` 验通路。

### 4.3 其它已有命令

| cmd | payload | 回包 | 说明 |
|---|---|---|---|
| `0x0602` | `reg(u8)+value(u16 LE)` | 无 | 直写 BK4819 寄存器 |
| `0x0760` | `addr(u32)` | `0x0761`+`addr(4)+status(1)` | 擦 4 KiB 扇区 |
| `0x0762` | `addr(4)+len(2)+data(≤128)` | `0x0763`+11 B | 写 |
| `0x0764` | `addr(4)+len(2)` | `0x0765`+`11+n` B | 读 |
| `0x0766` | `days(u32)+secs(u32)` | `0x0767`+9 B | 对时 |

**对时 `days` = 自 2000-01-01 的天数**（2026-10-25 → 9794），不是 Unix 天数。

写 flash：擦后等 60 ms，每 128 B 回读校验并等 8~12 ms，每次发命令前清接收缓冲。

## 五、数据表（v5，外置 flash 0x00162000）

```
16 B 头：<4s B B H I I> = "DPT1", version=5, count, hdr_size=16, data_off, date
  date = (year-2000)<<9 | month<<5 | day（首个过境的本地日期）
40 B 条目 × count：<16s I I I H H H H H B B>
  name[16] freq10(u32) data_off(u32) up10(u32)
  aos2(u16) dur_s(u16) pts(u16) step_ms(u16) ctcss10(u16) dayIdx(u8) max_el(u8)
  freq10/up10 单位 10 Hz（437.55 MHz → 43,755,000）
  aos2 = 本地当日秒 / 2
样点从 0x00165000 起，6 B/点：<h B H b> = offset_hz(i16), el(u8), range_km(u16), rate_10(i8)
校准数据 0x001FF000："DPC1" + ver(u8) + ppm(i32) + CRC16
```

旧表（v1~v4）拒收，屏幕显示 `NO DATA`。

- 连上电台 → 弹「电台已连接」（卫星、下行、上行）→ `只看不动` / `手机接管`

- 换页不交还（`liveTune` / `liveInfo` 提到 `MainScreen`，`CtrlState` 记着）

## 串口协议（重要）

38400 8N1，CDC-ACM，VID 0x36B7 PID 0xFFFF（安卓必须手动 prober.table.addProduct）

帧：AB CD | len(2 LE) | msg[n]+crc(2) 整体异或 MASK | DC BA
msg = cmd(2 LE) + payload_len(2 LE) + payload
CRC-16/XMODEM（初值0，poly 0x1021，MSB），对未混淆的 msg 算；奇数长度补 0x00
MASK（16字节循环）：16 6C 14 E6 2E 91 0D 40 21 35 D5 40 13 03 E9 80

命令：
- 0x0602 写 BK4819 寄存器 reg(u8)+value(u16)，无回包
- 0x0760 擦扇区 / 0x0762 写 / 0x0764 读 / 0x0766 对时
- 0x0768 外部控频开关 mode(1)，无回包
- 0x076A 固件自检 → 0x076B + proto/state/phase（3 字节）
- 0x076C 推帧（≥28 字节）→ 0x076D + state(1)
- 0x076E 页开关 on(1) → 0x076F + state(1)

state 位：0x01 接管 0x02 过境中 0x04 有表 0x08 武装 0x10 页开关 0x20 PTT按着 0x40 发射中

0x076C 载荷（LE）：rx10(u32) tx10(u32) dopp(i16) dist(u16) remain(i16) el01(i16)
rate01(i16) progress(u8) flags(u8) nameLen(u8) name[1..8]
—— 不足 28 字节固件整帧丢弃，短名字要补零。

对时 days 是「自 2000-01-01 的天数」（2026-10-25 → 9794），不是 Unix 天数。

## 数据表（v5，外置 flash 0x162000）

16B 头：<4s B B H I I> = "DPT1", version=5, count, hdr_size=16, data_off, date
  date = (year-2000)<<9 | month<<5 | day
40B 条目 × count：<16s I I I H H H H H B B>
  name[16] freq10 data_off up10 aos2 dur_s pts step_ms ctcss10 dayIdx max_el
  freq10/up10 单位 10Hz（437.55MHz → 43,755,000）；aos2 = 本地当日秒/2
样点从 0x165000 起，6B/点：<h B H b> = offset_hz, el, range_km, rate_10
校准 0x1FF000："DPC1"+ver+ppm(i32)+CRC16

## 十一、快速排错

| 现象 | 原因 | 处理 |
|---|---|---|
| 屏幕 `NO DATA` | 表版本不是 5 / 表头 CRC 错 | 用 PC/手机重写表 |
| `0x076A` 零回包 | ①没刷上我们的固件 ②探针帧漏 CRC ③电台停在刷机/DFU | 先用 `probe_fw.py` 验；对照 `proto` |
| 手机显示接管但电台没反应 | 电台停在主界面（phase=OFF），第二套页没启动 | 97,872 B 那版已改成接管自动进页 |
| 接管后整机是聋的 | 第二套逻辑没走 `DPH_BeginRun`，音频没开 | 接管时补 `DPH_AudioOpen()`（已加） |
| 信号表 -150 dB、功率乱跳 | App 用 0x0602 以 5 Hz 直写 REG_38/39，把 RSSI 窗口顶掉了 | 改成固件自己 `BK4819_SetFrequency()`，App 不再碰寄存器 |
| PTT 没反应 | ①EXT 阶段被 `ext_tx10` 门禁吞 ②按键没到页面 | 已放开；再看 App 状态行 `PTT按下 / 发射中` |
| `APP` 压住信号表 | `$J` 坐标和 `$D`/`dB` 重叠 | 排版器里挪 `$J`，重新导出 `doppler_layout.h` |
| 排版器预览显示 `$J` 字样 | 预览不认识这个占位符 | 已补 `$J:'APP'` |
| 交付的 `.cmd` 报怪错 | LF 行尾 / 中文 / `set ADB="..."` | CRLF、纯 ASCII、`set "VAR=value"` |
| App 连不上电台 | VID 没注册；或用了「连接电台」（模拟器无 USB） | 注册 VID；模拟器用「网络模式」 |
