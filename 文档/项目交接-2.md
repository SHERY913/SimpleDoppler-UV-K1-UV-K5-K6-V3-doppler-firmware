## 1. 项目是什么

泉盛 UV-K1 / UV-K5 V3（PY32F071，Cortex-M0+）跑 F4HWN v6.3.0（Armel/Fusion 分支）的自定义固件，给业余卫星（ISS、AO-91、SO-50…）做**多普勒自动纠偏**：

- 上行（144/430 段）跟着卫星算，下行接收频率实时跟着多普勒走；
- 两套玩法：
  - **第一套（离线）**：PC 工具把过境表写进电台的**外置 flash**，电台自己按表算，不需要手机；
  - **第二套（在线）**：手机 App 每 200 ms 用串口推一帧 `0x076C`，电台只显示 + 照做。

两套都能用，界面上是同一页（RUN 页）。

## 4. 串口协议（改代码必看）

38400 8N1，CDC-ACM，VID `0x36B7` / PID `0xFFFF`。

帧：`AB CD | len(2 LE) | msg + crc16 | DC BA`，
`msg = cmd(2 LE) + payloadLen(2 LE) + payload`，
CRC-16/XMODEM 对**未混淆**的 msg 计算（奇数长度补 `0x00`），先算 CRC 再对整体 XOR：
`MASK = 16 6C 14 E6 2E 91 0D 40 21 35 D5 40 13 03 E9 80`

| 命令 | 用途 | 回包 |
|---|---|---|
| `0x0602` | 写 BK4819 寄存器 | 无 |
| `0x0760` | 擦扇区 | 状态 |
| `0x0762` | 写 128 B | 状态 |
| `0x0764` | 读 | 数据 |
| `0x0766` | 对时（days 自 2000-01-01 + 秒） | 状态 |
| `0x0768` | 接管开关（无回包，实测回 `0x0769`+state） | `0x0769` |
| `0x076A` | 自检 | `0x076B` + proto/state/phase |
| `0x076C` | 推一帧（≥28 B） | `0x076D` + state |
| `0x076E` | 过境页开关 | `0x076F` + state |

**state 位**：`0x01` 接管 / `0x02` 过境 RUN / `0x04` 有表 / `0x08` 武装 / `0x10` 页开关 / `0x20` tx_hold / `0x40` 正在发射 / `0x80` **正在刷写 flash**（我加的，用来区分"真刷写"和"5 Hz 数据帧"）。

**0x076C 载荷（LE）**：`rx10(u32) tx10(u32) dopp(i16) dist(u16) remain(i16) el01(i16) rate01(i16) progress(u8) flags(u8) nameLen(u8) name[1..8]`，不足 28 字节整帧丢。

**flags 位**（`app/doppler.c` 里 `ext_flags`）：`bit0` 数据有效 / `bit1` 过境中 / `bit2` **只收不发（SSTV）** —— bit2 置上时电台 RUN 页显示 `RX ONLY`，按 PTT 只响两声不发射。

**外置 flash 表 v5**：`0x00162000` 起，16 B 头 `"DPT1" + ver(5) + count + hdr_size + data_off + date`；40 B 条目；样点 `0x165000` 起 6 B/点；校准 `0x1FF000` `"DPC1"`。旧版表（v1~v4）固件拒收，屏上显示 `NO DATA`。

## 5. 固件这轮到底改了什么（按时间倒序）

1. **v9（SSTV 只收）**：`doppler_layout.h` RUN 页 `"TX $Y"` → `"$V $Y"`；`DPH_Expand` 加 `case 'V'`（flags bit2 = `RX`，否则 `TX`）和 `case 'Y'` 的 `ONLY`。
2. **v8（写内存/画屏安全）**：`DPH_Put` 化截断处理、`DPH_TextWidth` 返回 `uint16_t`、大字路径自己夹 `line`/`x`、页面被抢走后 `dph_seeded = false`（差分推送失效点）、交还时 `released` 分支无条件还原。
3. **v7（15 处静默错误）**：`ExtPush` 的静态变量改成文件级并在每次接管时 `DPH_ExtSessionReset()`；`orig_code_type2/orig_code2` 分信道存亚音；交还时用 `saved_vfo` 而不是当前 `gRxVfo`；`DPH_AosLeft` 的跨日回绕；无表时不藏 TX 行；`snprintf` 越界走 `DPH_Put`。
4. **v6（逻辑复检）**：`ExtPush` 加 `ext_ctrl` 门（**以前 App 只是连着、没接管，也在改你的发射频率**）；`DPH_Enter` 不再清 `radio_saved`；KEY_8/9、KEY_EXIT 在 EXT 下也对。
5. **v5（一按 PTT 就完蛋那一批）**：TX 角标不再用 8×16 大字盖屏；发射频率同时写 `gRxVfo` 和 `gTxVfo`（交叉波段关掉时 `gCurrentVfo == gRxVfo`，只写一个等于没写）；接管时不再硬关亚音而是还原操作员的；发射中把过境页抢回来。
6. **v4（性能）**：EXT 页从"每 50 ms 无条件全页重画"改成**脏标记 + 帧到即画**（数据 2 Hz，画 20 Hz 是纯浪费，LCD 与 BK4819 共 SPI）；`DPH_Blit` 用 `memcmp/memcpy` 代替 896 次逐字节比较。
7. **v1（PTT 根因）**：把"串口会话活跃"和"正在刷写 flash"拆成两个倒计时（`gSerialConfigCountDown_500ms` / `gSerialFlashCountDown_500ms`）。5 Hz 的 `0x076C` 帧会不断刷新前者，导致接管期间永远"刷写中"，PTT 被四处吞掉。**只有后者能吞 PTT、能禁发**（四道闸门：CheckKeys 电平、`GENERIC_Key_PTT`、`RADIO_PrepareTX`、10 ms 周期强制停发）。

### 已知但故意没改的

- 交还后不会再 `DPH_Tune` 到过境表频点（故意，避免覆盖操作员信道）。
- 15 秒看门狗在发射中只收载波、不换页（故意）。
- 29 条 P2 清单还冻结在 `审查与修复清单.md`（P0/P1 已全修）。

## 6.5 ISS 频率（2026-10 核对过，别再写错）

| 玩法 | 收（下行） | 发（上行） | 备注 |
|---|---|---|---|
| 中继 cross-band repeater | **437.800** | **145.990** + CTCSS **67.0 Hz** | 电台这行是 `FM 中继` |
| 语音直通 | **145.800** | **144.490**（ITU 2、3 区，含中国）/ **145.200**（ITU 1 区，欧洲） | 不走中继，直接听飞过顶的 |
| SSTV | **145.800**（PD120） | — | **只收**，和语音同一个载波 |
| 分组 APRS | 145.825（VHF） | 145.825 | UHF 分组是 **437.550**，2026-03 临时测试用过 437.825（RSØISS，1200 bps） |

三条容易搞混的结论：
1. **437.550 是 UHF 分组频道，不是语音下行。** 老版本 `sat_freq.py` 把它当 ISS 下行写进过电台。
2. **语音下行在 VHF 145.800，不在 U 段。** 437.800 只在"走中继"时才是你收的那个频点。
3. **SSTV 2025-11-12 起坏过**：ARISS Series 30 发射约 2 小时后服务舱电台故障，之后只发 4 秒空载波，活动取消；主用 Kenwood D710GA 换成备件 D710E，服务舱电台停用数月，2026-03 做过临时 APRS 测试；2026-10-02～10-06 的 **Series 33** 说明已经恢复。做节目/给用户解释时别说"ISS 天天有 SSTV"。

来源：AMSAT-NL 频率页、DARC 2025-11-18、AMSAT-SM 2026-03-01（ANS-060 转载）、ARISS Francophone 2026-09（Series 33 公告）。

## 7. App（`android-app/`）

- `RadioSession.kt`：连接（USB CDC + 网络 127.0.0.1:7878）、`isReady`（连上 + `fwInfo` 问过一句才算数）、`markLost/markAlive`、`tryReconnect`、`verifyLink`、USB 插拔广播、`usbInventory`。
- `RadioLink.kt`：`ask()` / `pushExt()` / `fwInfo()` / `readExact()`。
- `MainScreen.kt`：四个页（数据/指向/列表/电台）。控频循环每 200 ms 推一帧；推失败 3 次或 USB 掉线 = 自动退出控频、跳回电台页、显示原因，并且**每 3 秒静默重连**，连上后自动重检固件自检。
- 电台页按钮：连接电台 / 断开 / 网络调试 / 实时控频 / 对时 / 测通知 / 测试跳跃 / 固件自检 / 算过境→写表 / **模式（中继通联 → 语音直通 → SSTV 收听，点一下换一个）**。
- 三种模式（`opMode` 0/1/2）每帧在控频循环里重算，切模式**不重连、不断控频**：
  - 0 中继：rx = `downMhz + 下行多普勒`，tx = `upMhz + 上行多普勒`（ISS 437.800 / 145.990 67 Hz）；
  - 1 语音直通：rx = `voiceRxMhz + 多普勒`，tx = `voiceTxMhz`（ISS 145.800 / 144.490）；
  - 2 SSTV：rx = `sstvMhz + 多普勒`，tx = 0，`flags |= 0x04`（电台那行显示 `RX ONLY`）。

## 9. 踩过的坑（省你时间）

- **CRLF**：`doppler.c` / `doppler_layout.h` 是 CRLF，补丁脚本里用 `\n` 拼多行字面量永远 0 命中。先 `raw.replace("\r\n","\n")` 匹配、写回时再还原。
- **补丁脚本**：`.gtmp/patch_*.py` 都是"先在内存改，最后一次性写盘；任何断言失败就不写"。失败后必须重新读文件，别拿 grep 的行号当内存索引（插入会使下标偏移）。`strip()` 会抹掉缩进导致 8/12 空格的同名行没法区分，要用带缩进的完整行比较。
- **adb reverse 会骗人**：TCP 连上不代表有人应答。必须真发一条 `0x076A` 收到回包才算连通。
- **`connectNet` 是异步的**：连上后立刻读 `link` 会拿到 null，`verifyLink` 要等最多 2.5 秒。
- **UI 对话框按钮**：App 的「电台已连接」弹窗，`只看不动` 和 `手机接管` **两个都会跳到罗盘页**，点完要重新点「电台」tab。
- **`taskkill`**：MSYS 下要 `MSYS_NO_PATHCONV=1` 且用 `/PID`，写 `//PID` 会报参数无效。
- **文件策略**：本机现在是 `danger-full-access` + 审批 never，别传 `sandbox_permissions`（会比当前模式窄而报错）。
