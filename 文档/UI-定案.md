## 2. 卫星详情页（重点重排）

上半部分总高 **< 390 dp**（小于半屏），过境表吃掉剩下的全部。

```
┌──────────────────────────────────────────────┐
│ AO-91                          [ 跟踪 ]      │  ← 名称 18sp 粗 + 两字按钮
│ 145.960 ↓ · 亚音 67.0 Hz                     │
│ 145.960 ↑        [历史][功能][故事] ▸         │  ← 右侧三颗折叠 chip
│ 距下一趟 12:40                               │  ← 秒级倒计时，右对齐同一行
│ APRS 145.825                                 │  ← 仅当这颗星有 APRS 时才出现
├──────────────────────────────────────────────┤
│  中继  │  通联  │  SSTV                       │  ← 玩法 chips（选中态必须显眼）
├──────────────────────────────────────────────┤
│ 未来 3 天过境            8 趟        ⚙ 步长   │
│ 21:04 → 21:15   max 89°   …                  │  ← 占余下全部，可滚
├──────────────────────────────────────────────┤
│ 名单 3                                     写入 │  ← 56 dp 吸底浮条
└──────────────────────────────────────────────┘
```

- **「跟踪」只有一个按钮**：连了手台 → 直接接管电台；没连 → 照样进罗盘页，屏上提示「未连接手台」。
- **APRS 不是玩法**：有 APRS 频率的星只在频率区多显示一行，不进 chips、不做包界面。
- **历史/功能/故事**：右侧三颗 chip，点开是弹层，正文来自 wiki 摘要（见 §7）。
- **玩法三个**：中继 / 通联 / SSTV。中继 = 通联页 + 双频双亚音；SSTV = 跟踪页的 SSTV 模式。玩法按星记忆，存 `Prefs`。
- **写表唯一入口 = 详情页底部浮条**（`名单 n` / `写入`，过境行右侧 `＋` 入列）。设置里删掉名单、写入、进度、超限提示；只保留「清空电台里的过境表（需长按）」与「写表前先读回旧表（备份）」。

## 5. 跟踪页与「按表跑」的语义（重要纠正）

- **「按表跑」不是一种 App 模式**：表写进电台后电台自己跑（10 ms 一拍），手机完全不参与。
- **跟踪页 = App 自己的计算与显示**：罗盘、读数、倒计时、过境时间线；有没有手台都照常工作。
- 连了手台 → 进入即自动接管、顺手推频；未连接 → 只显示，屏上提示「未连接手台」，**不出现「接管」按钮**。
- 因此**不存在**「按表跑 vs App 接管」切换开关。

## 6. UI 系统：作者用的网页排版器

**分层**：版面由**作者（我）**在网页里排；普通用户只能改主题色。

### 6.1 渲染模型
- App 内置通用渲染器：读 layout JSON → 画盒子。
- 设计基准 **360×780 dp**；`scale = min(屏宽/360, 屏高/780)`；画布 = 屏幕/scale，多出的空间由锚点吃掉（Unity CanvasScaler 的 `Expand` 模型）。
- 每个盒子可选四向锚点（L/R + T/B）；字号用 sp 不缩放；文字溢出 `autoShrink`；点击区 ≥ 48 dp（校验器强制）。

### 6.2 元素类型（第一版全支持）
矩形（填充/描边/圆角/透明度）、文本框、功能键（三态）、图标/图片、自绘组件占位（罗盘/天穹/世界地图/SSTV 图区）、列表（含行模板）、滑条/进度条、**开关、下拉选择、文本输入（含焦点与输入法）**。

### 6.2.1 自绘组件的可调参数（精选，不是无限）
- 罗盘：半径 / 刻度间隔 / 是否显示度数 / 指针颜色 / 背景环
- 天穹：仰角圈档位 / 星点大小 / 标签开关 / 三档颜色
- 地图：网格 / 国界 / 标签 / 昼夜线 开关
- SSTV 图区：等比 / 裁切 / 像素化

### 6.2.2 字体
只用系统字体：黑体 / 衬线 / 等宽三档（频率、时间、角度继续用等宽）。不内置字体、不允许导入 ttf。

### 6.3 编辑能力（"高度自由"，全部要）
- 图层树 + 分组（锁定/隐藏/改名/拖序）
- 旋转与变换（旋转/缩放/翻转 + 15° 吸附）
- 渐变 / 阴影 / 模糊 / 虚线描边
- 吸附与参考线（对齐线、等距提示、1/4/8 dp 网格、自定义参考线）
- 撤销重做 + 框选多选 + 快捷键（Ctrl+Z/Y/C/V/D、方向键 1 dp / Shift 10 dp）
- 组件实例（复用块，改主件全改，可调实例覆盖）
- 状态变体（常态/按下/禁用，行模板，空状态）
- 动画（最后做）：数值缓动、按键反馈、罗盘指针缓动、星点渐入、列表项与进度条。**页面切换不做动画**。

### 6.4 技术形态
- 工具：**Vite + React + TS 小工程**，模块化，每类元素一个组件，store 管理文档，拖拽用 rAF 批处理保 60 fps。落 `多普勒/PC工具/App排版器/`。
- App 端：**组件注册表**（每类元素一个 renderer，可插拔），与工具端概念一一对应。

### 6.5 绑定语法（白名单，不执行任意代码）
占位符 + 内置函数，例：
```
{sat.name}          {sat.norad}
{fmt.freq(state.rxHz, 3)}     {state.dopHz|signed}
{if(state.connected, "已连台", "未连接手台")}
{fmt.countdown(next.passMs)}
```
解析器自写（约 200 行，可单测）。

### 6.6 动作表（功能键能绑的函数）
```
nav.detail  nav.track  nav.back
radio.takeover  radio.release
sstv.start  sstv.stop  sstv.save
sstv.source.mic  sstv.source.ext  sstv.source.file
sstv.mode.set(mode)   sstv.autovisOn  sstv.autovisOff   sstv.autosaveOn  sstv.autosaveOff
playmode.set(relay|voice|sstv)
cart.add  cart.clear  cart.write
sheet.intro  sheet.filter
sky.offset±(min)   sky.now
tab.set(list|sstv|sky|map|settings)
```
（只增不改；删动作要同步升 schema 版本。）

### 6.7 分发与回退
- 真源：`assets/layout/*.json`（随 APK 发布）。
- **旁路只有作者能用**：`BuildConfig.DEBUG` 为真时才检查 `/sdcard/Download/layout.json`，存在则优先加载（右上角标「试排」）；release 包这段代码不编译进去。
- schema 带 `version`；版本不认 → 拒绝加载 + 回退内置版 + 顶角提示，不白屏。

### 6.9 工具预览数据
只用内置假数据，不连真机。假数据必须含**最长名压力样本**（`ISS (ZARYA)`、`CAS-4B`、`FOX-1B (AO-91)` 等）与超长读数（`145.987654 MHz`、`-12.7 kHz`），否则排版时看不出溢出。

### 6.10 覆盖范围
**八份 layout**：卫星列表 / 详情 / 跟踪（含 SSTV 模式）/ SSTV Tab / 天图 / 地图 / 设置 / 底栏。

## 7. 主题色（给普通用户）

- 现状：`doppler2/ui/UiTheme.kt` 的 `object Pal`，`Accent` 四选一（`:27-32`）+ `night` 纯黑夜视（`:49-62`）；全工程 `Pal.*` 引用 **371 处** —— 只改 getter 即可全局生效。
- 改成：用户选**任意 seed 色**（色环 + HSV 滑条 + 12 个预设点）。seed 不只做强调色，还给 `bg/card/line/grid` 做低饱和微染（色相偏移 5–12°，饱和度压到极低）。
- 底色仍是暗色；`night`（纯黑 + 红色）作为独立开关保留，**开启时覆盖 seed 色**（暗适应优先），设置里写明「夜视会覆盖主题色」。
- 浅色模式**不做**（371 处对比度按暗底设计）。

**批①踩到并已修的三个坑**
1. `screens` 必须是**对象**（`{"screens":{"sky":{...}}}`），写成数组会被判「缺 screens」→ 整页空白。
2. 自绘件 `Canvas(Modifier.pointerInput(...))` 不带尺寸修饰符会被量成 0 → 天穹整块空白；必须 `.fillMaxSize()`。
3. 试排旁路原来读 `/sdcard/Download/layout.json`，Android 11 上 App 无存储权限 → 静默跳过、没有任何提示。改为优先读 `getExternalFilesDir(null)/layout.json`（同一个 `adb push` 能进，无需权限）。
