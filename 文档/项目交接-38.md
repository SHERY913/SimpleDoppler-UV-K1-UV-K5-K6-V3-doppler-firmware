### 几何三句（改之前必须读懂，读不懂就别改）

1. **气泡位移 = 参照方向在「垂直于指向轴的那个平面」上的投影**。参照方向：有目标 = 卫星方向，
   没目标 = 天顶（所以自动变成水平仪）。
2. 指向轴 `-Z`（默认）时那个平面就是屏幕平面，气泡取 `X/Y` 分量；`+Y` 时取 `X/Z` 分量
   （否则气泡只会左右跑）。
3. 误差 ≤90° 与 >90° 的 `sin` 相同、方向翻 180°：手机翻过 90° 气泡会从内圈往回走并翻到对面，
   这是水平仪的物理行为，**不要钳**。`backwards=true` 时红圈画空心、状态行写「指反了」。

### 四个必须记住的坑

1. **矩阵的列才是设备轴**：`v_world = R · v_device`，`col j = (rot[j], rot[3+j], rot[6+j])`。
   取行等于把"重力方向"当"手机指向"，手机竖立时方位错 180°。
2. **"平放却显示倾 179.5°"不是 bug**：加速度计读 `(0.11,0,-9.94)`、四元数 `w≈0`，
   两条证据同向 → 那台手机当时**屏幕朝下扣着放**。定案用
   `adb shell dumpsys sensorservice`，别看数不对就先改公式。
3. **无目标时不能用"指向轴 vs 卫星"的公式**：参照是天顶而 `-Z` 指天底，恒差 180°-倾角，
   屏上会写「指反了 102.7°」。现在两口径：有目标 `acos(p·target)`，无目标 `acos(FRONT·天顶)`。
4. **版面**：盘 300 dp 装不下（超 360×780 约 69 dp，"记一笔/交还"被挤出屏）→ 盘 264 dp +
   读数区 `weight(1f)+verticalScroll`；模拟模式的剩余时间必须用 `SimPass.remainS()`。

  要贴边就让容器在 JSON 里写 `"anchor": "lrtb"`。

- Android 单测环境没有 `java.awt`（`javax.imageio` 编译就红），PSNR 用裸 `*.rgb` 字节比。
- `SstvEndToEndTest` 的素材目录要按序探测 `app/build/sstv-fixtures` 等四处（Gradle 单测 cwd 不定）。
- VIS 的 30 ms 停止位本身就是 1200 Hz，紧贴第一行 9 ms 同步头 —— 别在首行再开宽窗找 sync，
  会抓进停止位里，整幅左移 43 像素。
- `Expr.eval("{if(...)}")` 不做模板求值（返回空），模板必须用 `Expr.template`。
