# 卫星多普勒跟踪（SSTV 版固件）使用说明

一句话：电脑算好卫星过境时"频率该怎么变"，把一张表塞进对讲机；对讲机按 F+0 打开跟踪页，按 M 开始，它自己跟着卫星跑频率，声音从喇叭/耳机插孔出来，手机录音。

---

## 0. 先搞清楚为什么需要这个

卫星飞过来时，你和它之间的相对速度从 +7 km/s 变到 −7 km/s（ISS 级别），
145.800 MHz 上的接收频率会从 **+3.6 kHz 一路滑到 −3.6 kHz**，一共 7 kHz 跨度。

FM 解调本身不在乎这点偏移，但：

- 信号滑到中频滤波器边缘 → 声音失真、噪声变大；
- 滑出静噪门限 → 声音直接被掐断（这就是"录到一半没声了"的主因）。

所以真正要做的不是"改音调"，是**把这个 7 kHz 的滑动抵消掉，让信号始终停在中频正中间**。
本固件每 10 ms 检查一次该补多少，直接改收发芯片（BK4819）的频率字，全程不碰静噪、
不碰音频通路 —— 所以**跟踪过程中没有咔声、没有断音**。

## 1. 刷固件

### 1.1 已经编好的 bin（直接用这个）

刷 `交付/f4hwn.sstv.doppler.bin`。**字节数和 md5 只在 `交付/README.md` 里写一份**——
每重编一次 `__DATE__/__TIME__` 就把 md5 改掉，这里复述一遍必然变成过期数字，
照着它去认固件只会认错（这一份的指纹、历史归档和"哪份缺哪处修复"都在那边）。

> **表格式是 v5**（条目 40 字节 + 每点 6 字节 + 样点区从表头后整 4 KiB 起），
> 换固件后必须重新点一次「写入电台」：旧表会被判版本不符或被 `data_off` 自洽检查
> 拒收，屏幕上分别显示 `VER <表里那个版本号> ONLY` 和 `BAD LAYOUT`，不是 `NO PASS TABLE`。

- **这一版是 Fusion 底座 + 多普勒页，主动裁掉了一批跟收图无关的功能**。
  多普勒页里另外有：时钟 / 定时开始 / 晶振校准 / 发射（上行补偿 + 亚音 + 6 键换功率）。

  **保留了**：多系统、CHIRP 写频（USB/UART）、宽频接收、基础扫描、手电筒、
  键盘锁、双守、各类亚音编解码、开机自检、电池管理、`BK4819` 寄存器实时读写（0x0601/0x0602）。

  **这一版没有的**（实测省下的字节）：
  频谱扫描 8,788 / FM 收音机 5,508 / 收发日志界面 4,284 / 快速扫描 2,148 /
  扫描进度条 2,004 / 扫描信号格 672 / 扫描亚音 504 / VOX 声控 868 / 信号条 580 /
  K5Viewer 2,000+。
  > 这些功能在**别的系统槽**里刷官方 Fusion 就能用 —— 内部 Flash 有 5 个槽，
  > 按住 MENU 开机可以切换，不用为了频谱在这台上将就。
- **用官方 ARM GCC 13.3.0 + 官方链接脚本 `Core/py32f071xb.ld` + 官方 nano newlib 编的**。
- 起始地址 `0x08002800`、栈顶 `0x20004000`，与官方 Fusion bin 布局一致，
  **用你平时刷 Fusion 的那套工具（k5tool / UVTools / 官方升级工具）直接刷**。
- **多系统**：`MULTIBOOT` + `HOT_CFG` + `OVERLAY` 全开（Fusion 本来就是开的）。
  按住 **MENU** 开机 → `F4HWN MULTIBOOT` 选择器；不按就正常开机。菜单里 `CFG M` 也是它。
- 万一刷进去不开机：断电，**按住 PTT 再开机**进原厂 bootloader，刷回官方 Fusion 即可
  （bootloader 在内部 Flash 最前 10 KB，刷固件不会碰到）。

> 说明：之前给过的几个包（现在改名为 `f4hwn.sstv.trim*.bin`）是**裁剪版**——砍了 60 多个功能宏，
> 体积只有 73~91 KB。既然你反馈 USB 连不上，而裁剪版和官方 Fusion 的唯一区别就是"砍掉的那些功能"，
> 所以这一版把砍掉的全还回去了，用官方 Fusion 的原始宏表重编。**如果这版还连不上，那就不是裁剪的问题。**

> 注意：`MULTIBOOT_OVERLAY` 必须开着，否则多系统里"刷回固件"那段代码（`MB_RamReflash`，888 字节）
> 会落到 `.data` 里，把 RAM 前 0x280 的保留区顶爆，链接脚本直接抛
> `RAM before the overlay exceeds the fixed 0x280 anchor`。

### 1.2 自己编（推荐，等价的官方工具链）

源码在 `_src/uvk1-v6.3.0`，已经加好 `SSTV` 这个 preset（继承 Fusion，砍了 65 个宏）。

```bash
cd _src/uvk1-v6.3.0
cmake --preset SSTV
cmake --build --preset SSTV
```

产物：`build/SSTV/f4hwn.sstv.bin`

> 保留宽频接收、USB、手电筒，**打开多系统启动**（按住 MENU 开机选槽），新增多普勒跟踪页。

## 2. 把过境表写进对讲机

在对讲机屏幕根部没有时钟，所以它不自己算过境，只负责"照着表跑"。表由电脑生成。

### 2.1 准备

用发布出来的 **`DopplerPass.exe`**（或 `DopplerPass-0039.exe` 这类带日期的那份）就行，
里面已经带好 Python 和依赖，不用装任何东西。
从源码跑才需要：

```bash
pip install sgp4 pyserial numpy
python doppler_tool.py
```

TLE（卫星轨道根数）每天在变，**一定要用当天的**。工具自己联网抓
（点「更新 TLE」，走 Celestrak 的 amateur 组，缓存进 `tle_cache.json`），
不需要手动下载文件；抓不到时会退回缓存并在列表上标出「最老数据是几天前」。

### 2.2 上传

工具里的顺序是：**选星 → 填地面站和参数 → 「重新计算」 → 勾选要写的过境 →
（可选）「＋ 加入待写」攒一批 → 选串口 → 「写入电台」**。

| 界面里的字段 | 含义 |
| --- | --- |
| 纬度 / 经度 / 海拔 | 你的地面站（东经、北纬为正），海拔米 |
| 天数 | 往下算几天，范围 1~10；想写更久的分几次写 |
| 最低仰角 | 默认 10°，低于这个角度基本收不到 |
| 采样间隔 | 默认 10 s，**最小 5 s**（固件拒收比这更密的表；越小越平滑、表越大） |
| 串口 | 「刷新端口」重新列举；插上电台、开机再看下拉框 |

「加入待写」可以把几次计算的结果攒成一张表（跨卫星也行，写入前按时间排好）；
「写入电台」之前会弹一个确认框，写清楚**擦几个扇区、写几段、多少字节**。

清空表（把表区擦成空白，电台屏幕会显示 `NO PASS TABLE`）：

```bash
python clear_table.py            # 会先列出归属再问你一次
```

> 早期版本这一节写的是命令行工具 `doppler_upload.py`（`--days/--tle/--dry`，
> 采样默认 2 s、最多 32 趟）。那个脚本已经删了，参数口径也全部过期 ——
> 现在只有 GUI 这一条路，参数以 GUI 为准。

### 2.3 表格存在哪

`0x162000` 起 **64 KiB**（16 个 4 KiB 扇区，到 `0x172000` 为止）。

这块地是按**白头佬汉化包**挑的：汉化包把 40 个 app 排到 `0x152000` 为止，
`0x162000..0x180000` 那 384 KiB 里唯一没人要的空地就是这里，
上面到汉化字库（`0x180000`）还留 57,344 B 缓冲，下面正好是 48 个 app 槽的声明区末尾
（`0x102000 + 48 × 8 KiB`）——再多 4 KiB 就把第 48 槽吃掉，编译期就过不去。

表头占第一个扇区（`0x162000..0x162FFF`），样点从 `0x163000`（`DPH_SAMPLE_OFF 0x1000`）起，
每点 6 字节。一条 10 分钟过境按 10 s 一点 = 61 点 = 366 B；5 s 一点 = 121 点 = 726 B。

**能写几趟由这张表的实际字节数决定，不是一个固定数字**（交接-22）：

- 条目区（`+16..+0x1000`，4,080 B）放 `40 B × 条数`，`DPH_PASS_MAX = 102` 正好填满；
- 样点区从 `+0x1000` 到表区末尾（61,440 B），每趟 `40 B 条目 + 点数 × 6 B`；
- PC/App 构表时按真实占用算：装不下就提示**去掉最后几趟**（列出具体哪几趟），
  而不是先用条数把天数砍掉。实测 ISS 20 天窗口：10 s 档 102 趟占 39 KB，
  5 s 档 95 趟占 65,310 B（99.7%）。

> ⚠ 原厂镜像（只有单系统、没装过汉化的机器）里这块地躺着**语音包的尾巴**。
> 第一次在那种机器上写表，归属检查会判定"这里不是多普勒的表"并**拒绝擦除**——
> 这是故意的。确认要把那 64 KiB 让给过境表，再在工具里手工放行一次即可；
> 语音包完整的原始镜像（607,504 B ≈ 75.9 s）在 `临时/voice_pack_full.bin`。

> 采样间隔为什么要 10 s：固件 `DPH_OffsetAt()` 本来就是线性插值，10 s 栅格
> 相对 1 s 的误差约 6 Hz（437.8 MHz 上多普勒二阶导峰值 0.5 Hz/s²），
> 而 NFM 带宽 2.5 kHz —— 差 400 倍。用 1 s 采样换来的精度肉眼不可见，
> 代价是体积 ×10，那才是表区当年被撑到 496 KiB 的原因。

---

### 2.4 表格式 v5（2026-10 起）

表头 16 字节：`"DPT1" ver count hdr_size data_off reserved`。

每条 40 字节：`name[16] freq10 data_off up10 aos_min dur_s pts step_ms ctcss10 flags max_el`。
`up10` 是**上行频率**（10 Hz 单位，0 = 纯接收）、`ctcss10` 是上行亚音（0.1 Hz，670 = 67.0 Hz）。
工具会自动从 `sat_freq.py` 的 `UP` 表里带出来。

样点从 `data_off` 起，每点 **6 字节** `<hBHb>`：
`int16 多普勒偏移Hz + uint8 仰角 + uint16 斜距km + int8 径向速度(0.1km/s，负=接近)`。

- 条目上限 **102 条**（固件 `DPH_PASS_MAX`、PC、App 三端同一个数，`verify_layout.py` 当场比）：
  这是**条目区**的物理上限（`16 + 102×40 = 4,096 = DPH_SAMPLE_OFF`），再多一条就压进样点区。
- 真正决定装不装得下的是**字节数**：表区 `0x162000..0x172000` 共 **64 KiB**，
  每趟 `40 B + 点数 × 6 B`。10 s 一趟 946 B、5 s 一趟 1,846 B（1,500 s 满长），
  所以同一片地表能装的趟数随采样密度浮动 —— 工具按实际字节判，超了让你少选几趟。
- 采样间隔**不得小于 5 s**（`DPH_STEP_MS_MIN`）：写更密的表会被固件整表拒收；
  PC 与 App 在打包阶段就先拦住并说明原因。默认仍是 10 s（精度差 400 倍以内）。
- 写入时会**先按时间排序**再写，所以机器里翻 ▲▼ 就是时间顺序。
- **工具连上电台会自动对时**（新命令 `0x0766`），不用再手按十位数字。
- **旧表不兼容**（v1/v2/v3 全部拒收，屏幕显示 `NO PASS TABLE`），刷完新固件必须重写一次。

## 3. 机器上怎么操作

### 3.0 四个阶段（这一版新增预听与尾音）

卫星的**电磁**升落比**几何**升落早一点、晚一点（大气折射 + 天线旁瓣），
所以"时间一到才开始、数组一跑完就退出"两头都会丢信号。现在这一页是四个阶段：

```
   READY 就绪  ──M 短按──────────────▶  TRACKING 跟踪  ──自动──▶  POST-LISTEN 尾音  ──EXIT──▶ 退出
      │  │                                  │                                │
      │  └─M 长按─▶ PRE-LISTEN 预听 ──M──┘   └──EXIT 进尾音                  └── 侧键二换亚音 / PTT
      └──EXIT 退出          （预听页 EXIT 回就绪）
```

| 阶段 | 频点由谁定 | 能做什么 |
| --- | --- | --- |
| **READY** | 表里的标称频率（偏移 0） | ▲▼ 选过境、短按 M 立刻跟踪、长按 M 进预听并武装 |
| **PRE-LISTEN** | 数组**第一个样点**（AOS 那一刻的偏移） | 静噪全开先听着，PTT 发射、侧键二换亚音；**多普勒定时器还没跑**；频率不手动改（几百赫兹的残差靠 FM 捕捉吃掉）；EXIT 回就绪页 |
| **TRACKING** | 每 100 ms 按数组改一次 | ▲▼ 挪进度（步长由 1 键选）、6 换功率、1 换步长、3 换带宽、侧键二换亚音、PTT 发射 |
| **POST-LISTEN** | 数组**最后一个样点**（LOS 那个偏移） | 停在这儿继续听尾巴、侧键二换亚音、PTT 回叫；频率不手动改；EXIT 才真正退出还原 |

数组跑完**不会**自己退出，也不会再把静噪关回去（这是这一版改掉的核心行为）。
只有 EXIT / 退页才把信道、静噪、喇叭、键盘锁还给操作员。

### 3.0.1 按键

| 按键 | 作用 |
| --- | --- |
| **F + 0** | 打开多普勒页（原来这俩键是开 FM 收音机，本版已换掉） |
| ▲ / ▼ | **就绪页**：选第几个过境。**跟踪中**：把整条曲线往前/往后挪一格，**格长 = 1 键选定的 1/2/5/10 秒**（按 M 晚了、或晶振残差攒出偏差时用；长按连发）。**预听页 / 尾音页**这两键不动作 |
| M（短按） | **立刻按表跟踪**，不看时钟也不问 AOS —— 就绪页、预听页都能按。早于 AOS 按也安全：原点被推到真 AOS 上，到点之前一直停在第 0 个样点（AOS 那一刻的偏移）。没校过钟的机器上这是唯一能跟这颗星的路子 |
| **M（长按）** | **进预听页并把这趟武装上**：时钟校过（`DPH_AosLeft() >= 0`）就到 AOS 自动开跑，**提前多久都行**，不是只有 60 秒；没校过钟就只进预听，等着你按 M |
| **1** | **跟踪中 ▲▼ 一格的步长**：1 → 2 → 5 → 10 秒循环，出厂 1 秒。屏上跟踪页左下角 `S3s` 就是当前档 |
| **3** | **接收带宽**：25 kHz ⇄ 12.5 kHz 来回切。屏上就绪页 `BW 25k`（底行 `M RUN` 与 `EXIT` 之间）与跟踪页 `BW 25k`（步长右边）跟着变；发射中切也当场生效 |
| **6** | **发射功率三档**：5W → 2.5W → 1W 循环，进页默认 5W |
| **8** | 设置时钟（输入 `MMDDHHMMSS` 十位数字，MENU 确认；跟踪中锁死） |
| **9** | 校准晶振（见 3.1；跟踪中锁死） |
| **0** | 信息页（固件版本、表条数、当前阶段号、校准 ppm）；页内再按 0 或 EXIT 退出 |
| PTT | 发射（只有表里带上行频率的卫星才有反应）。四个阶段里 READY/PRE/RUN/POST 都能按 |
| **侧键二** | **换上行亚音**：只在 67.0 / 74.4 / 141.3 / OFF 四站及写表那颗之间循环（表值 → 67.0 → 74.4 → 141.3 → OFF → 回表值）。**正在发射中按也立刻生效**（改配置之外还当场补写芯片那对亚音寄存器）。读数在 `$Z` 那格；这一趟没有上行时整格不画、按了双响拒绝。只认按下那一下，长按不连发 |
| **侧键一** | **SO-50 唤醒专用键**：按住就以 **74.4 Hz** 亚音发射（表里原亚音先存起来，松手还原），松手即停；只在多普勒页生效，其它页面和 `F + 侧键一` 都不受影响。和 PTT 可以交叉按 —— 谁按着谁发射。**注意 74.4 Hz 只负责"唤醒/续期"，卫星的转发门是用 67.0 Hz 开的**：点一下侧键一唤醒，再用侧键二切到 67.0 后按 PTT 通联（10 分钟内有效，再按一次侧键一续 10 分钟） |
| **F（长按）** | **键盘锁开关**：多普勒页里长按 F 上锁，屏幕顶行最右亮起**小钥匙**；再长按一次解锁。锁着时只有 PTT 与长按 F 有反应（app.c 的键盘锁闸门本来还留了发射中放行的口子，这一页自己又挡了一道）。短按 F 照旧吞掉 —— 这一页没有 F 组合键 |
| EXIT | 预听 = **回就绪页**（留着选好的星和亚音，武装作废）；跟踪 = 进尾音；尾音 = 退出并还原；子页面 = 返回；就绪页 = 退出多普勒 |

> 这台机器的键矩阵是 5×4，**没有旋钮、也没有左右键**（整个固件里没有编码器驱动）。
> 所以"挪进度"只能落在 ▲▼ 上：就绪页是选星，跟踪页是挪一格。预听/尾音页这两键不动作 ——
> 那两页停在固定样点上，几百赫兹的残差交给 FM 捕捉效应。
> `PRE-LISTEN` / `POST-LISTEN` 用 6×7 粗体横幅是**宽度问题**：大字那一档一格 13 px，
> 10 个字母就是 130 px，超过 128 会被砍字，而且它吃两行、正好压在下面的频率上。
> （大字本身能画字母——过境页那套 7×16 走 `gFontBigPacked`，`'!'..'~'` 94 个字形齐全；
> 只有主界面那套大字是纯数字的 `gFontBigDigits`。）

### 3.1 时钟与晶振校准（为什么必须做）

芯片**没有 RTC**，时钟是用主晶振数出来的。这颗晶振出厂有 ±1.5% 左右的偏差，
换算到 145.8 MHz 就是 **±2000 Hz** 上下 —— 定时 30 分钟会偏 27 秒，
频率直接滑到滤波器边上。校准一次之后残差约 0.1%，30 分钟只差 2 秒 / 100 Hz。

**设时钟**：插上 USB、用配套工具写入一次表，**自动对时**（`0x0766` 命令）。
不想连电脑也可以手按：按 `8` → 输入十位 `MMDDHHMMSS`（例 `1102224107` = 11-02 22:41:07）→ MENU 确认。
时钟只存在内存里，关机后归零，所以每次开机想用「定时开始」都要重新设一次。

**校准**（一次就够，掉电不丢）：

1. 按 `9` 进校准页
2. 在整分钟（比如 22:00:00）按 **M** 开始内部计数
3. 等 10~30 分钟（越久越准）
4. 到点看手机/电波钟，**直接打六位真实时间**（如 `223000`），MENU 确认
5. 屏幕 `CAL 1.0062` 就是校准后系数，写在**外置 flash 最后一个扇区 `0x1FF000`**
   （`DPH_CAL_ADDR`，不在 `0x162000..0x172000` 的表区里，所以重写表不会把它抹掉）

### 3.2 定时开始怎么用

1. 先按 `8` 把时钟设准（否则倒计时无意义）
2. ▲▼ 选中要等的那条过境
3. **长按 M** —— 直接进预听页（横幅 `PRE-LISTEN`），左下角那格从 `M RUN` 变成 `ARMED`
4. **提前多久都行**（十分钟、半小时都可以），只要这颗星的 AOS 还没到：进页那一刻
   静噪已经打开、频点停在 AOS 那一刻的偏移；留在这一页听着，倒计时一直走
5. **AOS 前 60 秒三声提示**、前 10 秒再三声（音频早就在进页那次开了，不会再跳一次）
6. **到 AOS 自动进跟踪**
7. 数组跑完自动进 `POST-LISTEN`，不退出；按 EXIT 才退

> 想反悔：预听页按一下 **EXIT** 就回就绪页，星和亚音都留着，只是武装作废（要再等就
> 重新长按 M）。彻底退页要回就绪页再按一次 EXIT。

### 3.2.1 按晚了 / 计时不准：±1 秒挪进度

跟踪中按 ▲ 把整条曲线往前挪一格，按 ▼ 往后挪一格；**一格多长由 `1` 键选**：
1 → 2 → 5 → 10 秒循环，出厂 1 秒。中段多普勒变化率大约 250 Hz/s，1 秒一格很顺手；
末段每秒只剩几十赫兹，一格 1 秒就把整段尾巴一步跨过去；折射尾巴和低仰角出星
那两分钟又恨不得 10 秒一步（长按连发）。

用在两种场合：你按下 M 的时刻比 AOS 晚了几秒；或者这颗晶振残差把时间轴拖了
几百米之外。**挪的是时间原点，不是频率** —— 偏移仍然按数组在那个时刻查，
所以进度条、剩余时间、`$O` 数字会一起跟着跳过去，不会出现"屏和芯片各挪各的"。

上限封顶在这一趟的末尾（不会一按就跳到尾音页）；往前挪过 t=0 之后原点落在未来，
跟踪页就停在第 0 个样点等 AOS，不会回绕成四十多亿（那是修掉的老 bug）。

### 3.2.2 一张表最多跨 16 个本地日

条目里的"第几天"只有 4 bit（`0..15`）。以前第 16 天会被静默折回第 0 天：
电台上日期少 16 天、倒计时和"定时开始"跟着算错，而且**表本身写得很成功、
校验也不报错** —— 只有屏幕骗人。现在 PC 与 App 在构表时就拒绝并说清是哪一趟，
所以一次别攒跨 16 天以上的队列（GUI 单次计算本来就限在 10 天内）。

### 3.3 发射

表里带**上行频率**的卫星（ISS、AO-91、SO-50、FO-29、RS-44、AO-95、AO-85、AO-7、
AO-73、JO-97、XW-3、PO-101）才能发；表里 up=0 的星按 PTT 不会有反应。

- 接收时每 100 ms 修正一次**下行**
- 发射时每秒修正一次**上行**，方向和下行相反
  （`上行频偏 = −下行频偏 × 上行频率 ÷ 下行频率`），一次乘法就够，V/U 和 U/V 都对
- 发射时改得快会被对方听到「咔」，所以故意放慢到 1 秒一次
- 亚音（CTCSS）从表里读，写进发射参数并在 key-up 时落进芯片；表里没写亚音就不发亚音
- **临时换亚音：按侧键二**，在 67.0 / 74.4 / 141.3 / OFF 与写表那颗之间循环。
  这颗只在本次停留期间有效（换过境、重写表、关机都回到表里那颗），
  屏幕上那格 `$Z` 一直显示**真正装进发射配置**的那颗，不是你以为按下去的那颗；
  **按着 PTT 换音也一样当场生效**——原来这里只改配置，而配置要到松手再按下才被
  读进芯片，于是"屏上写着换了、空中还是旧音"，而注释里写的正是"对方要求换一个音"
  那一刻（`doppler.c` 的 `DPH_SetTone`）
- **按 PTT 后屏幕会切到主界面**（这是原厂发射流程，会显示信道和功率），
  松开 PTT 约半秒后**自动回到多普勒页**，追踪不中断
- **侧键一 = SO-50 唤醒键**：按住就以 **74.4 Hz** 亚音发射（`CTCSS_Options[3]`，芯片侧
  换算成控制字 1536，13 bit 字段装得下，不存在"太低发不出去"的问题），
  松手立刻还原原来的亚音（存的是原始 `CodeType`/`Code`，所以 DCS 也能原样还原，
  不是只能还原 CTCSS）。只在这台机器的多普勒页生效，其它页面的侧键功能、`F + 侧键一`
  组合键都不受影响；和 PTT 可以交叉按，谁按着谁发射，两个都松开才停。

  **SO-50 的正式操作顺序（AMSAT 口径，两个音不是同一个用途）**：

  1. 145.850 发 **74.4 Hz**，给星上 10 分钟定时器"开门"；
  2. 在 10 分钟窗口内用 **67.0 Hz** 正常通话（67.0 才是转发器的 PL）；
  3. 窗口里再发一次 74.4 Hz，定时器续期。

  所以本机流程：**点一下侧键一**（74.4 唤醒，按一下即可，不必按住说话）→
  用**侧键二**把上行亚音切到 **67.0** → 按 PTT 通联；快到 10 分钟时再点一次侧键一续期。
- 想改发射功率：**直接按 6**，循环 5W → 2.5W → 1W；进页默认 5W。
  追踪页 `TX` 那排右边一直显示当前功率
- 发射被原厂拒绝（比如电量低、忙锁）时，半秒后也会自动回到追踪页

页面（实际排版可在 `layout_editor.html` 里自己拖，导出 `doppler_layout.h` 后重编；

## 4. 录音

对讲机 3.5 mm 耳机口 → 手机录音（或录音笔）。手机端用 SSTV 解码 App
（Robot36 / SSTV Encoder / Black Cat 之类）直接录下来解码，或先存成 wav 事后解。

因为跟踪期间静噪是开着的，弱信号也不会被掐断，只有真的没信号才会有噪声。
AOS 前后各留 30 秒余量开始录，PD120 一张图 2 分钟，别急着停。

## 5. 出问题怎么办

| 现象 | 检查 |
| --- | --- |
| `NO DATA / LOAD TABLE VIA USB` | 表没写进去：重跑一遍「写入电台」，它自己会整表回读比对 |
| 屏幕上是 `BAD LAYOUT` | 这张表是旧排版（样点区不在表头后整 4 KiB 处）写的，比如手机上那个 1.5 版 APK。用 PC 工具重写一遍即可 |
| 上传报 `erase FAILED` | 串口波特率/端口不对；确认刷的是 SSTV 版（带了 0x076x 命令） |
| AOS 时间和实际差很多 | TLE 太旧，换当天的；或时区不是 +8 |
| 跟踪了但没声音 | 静噪全开了还是没声，说明真没信号：换更高仰角的过境 |
| 声音有节奏性的"咔" | **不是步长问题**：采样间隔最小就是 5 s，写 1 s 的表固件整表拒收（§2.4）。发射中每秒一次的上行补偿是设计内的节拍，若仍然觉得吵，把 `logs/pc-*.log` 和现象记下来上报 |
| 偏移一直是 0 | 表里样点全 0：上传时用了错的 TLE 或频点参数 |
| SIG 一直是 `.....` + `-155 dBm` | 正常，说明当前频点没信号；有信号时格数会跳上去 |

## 8. 这一轮代码审查修掉的问题（都在 `doppler.c`）

写完之后逐行复核，发现并改掉 5 个真问题，其中第 1 条会直接废掉整个功能：

1. **每 100 ms 关一次音频**。原来照抄频谱扫描的写法，换频前后把 `BK4819_REG_30` 写 0 再复原。
   那个寄存器 bit 9 是 **AF DAC 使能**，写 0 等于关掉喇叭输出几微秒 —— 扫频只看 RSSI 无所谓，
   可我们唯一要的就是音频，每 100 ms 掐一次会变成"哒哒哒"。现在只写频率字 `REG_38/39`，不碰 REG_30。
2. **信号强度格数是反的**。`BK4819_GetRSSI_dBm()` 返回 `-160…+95`，我原来先取绝对值再比阈值：
   满格信号（+95，即 RSSI 饱和）会被算成 2 格，空频道（-155）反而 5 格。改成直接对带符号的 dBm 比较。
3. **退出时静噪阈值取错频段**。还原顺序原来是"先配静噪、再改回频率"，而阈值表是按当前频率选
   频段（VHF/UHF 两张表）的 —— 你在 430 MHz 用，退出后会拿到 145 MHz 的阈值。现在先还原频率再配静噪。
4. **喇叭状态没还原**。进入时强制 `gEnableSpeaker = true`，退出没恢复，耳机模式下会被强行开外放。
5. **多普勒页的多过境分不清日期**。原来只显示 `HH:MM`，两天预报里同一个钟点会出现两次，
   选错了就是照着另一条曲线跑（频率反着走）。表里 `flags` 低 4 位现在存"第几天"，界面显示 `D0/D1`，
   时间也改成**本地时间**（脚本 `--tz`，默认 +8），不用再自己拿 UTC 换算。

顺带改的：背光只在就绪页/跟踪页常亮（完成页不再一直亮着耗电）；进度条填充与边框对齐；
`printf` 格式全部走工程自带的最小实现检查。
