## 1. 固件

`f4hwn.sstv.doppler-fixed-20261027.bin`
- 大小 100512 字节，md5 `0cf725c8d1971e3d242ad37532c212e3`
- 基座：官方 Fusion 预设 + DOPPLER 页（`.gfw.py`，93 个 TU 全编，link rc 0）
- 资源：RAM 12768 B / 16 KB（77.93%），FLASH 99624 B / 118 KB（82.45%）
- 源码改动全部在 `_src/uvk1-v6.3.0/App/app/doppler.c`、`doppler.h`、`doppler_layout.h`、`uart.c`，每处都有 `FIX(...)` 注释

### 修了什么（对照报告第九部分 9.1）

**P0 三条，全部是 32 位整型溢出**
1. `DPH_TxOffset`：437.8 MHz 上行在偏移 > 4904 Hz 时溢出 → 过境中段上行被推偏几十 kHz。改 int64 乘。
2. `DPH_ClockSec`：开机 29.8 h 后时钟校正量溢出 → 时钟乱跳。改 int64 乘。
3. `DPH_Q1000`（新）：`dur_s > 4295 s` 的过境后半段插值回绕到表头 → 频率/仰角/距离重放。4 处调用统一。

**显示一致性**
4. `$V` 在第二套下不再"没发射也写 TX"（改成与三角标同源）。
5. `$C` 在第二套下恢复墙钟（原来被卫星名顶掉）。
6. 第一套 PTT 现在带多普勒补偿（原来发标称上行、屏幕却显示补偿值）。
7. 武装后进菜单不再让整段过境作废；READY 页多一个 `ARMED` 提示（`$!`）。

**健壮性**
8. `DPH_Tune` 加 29~1300 MHz 范围校验（坏表项不再把芯片点到 0 Hz）。
9. `DPH_Tune` 写 `saved_vfo`，交还时不再漏掉被污染的 VFO。
10. 校准 ppm 写路径钳位；EXIT 放弃校准会清 `cal_run`。
11. 表头 date 为空时年份用 2026 兜底（对时不再落到 2000 年）。
12. `0x0764` 读命令不再把发射锁 6 s（PC 逐块读整表时 PTT 一直是拒绝音）。
13. 清掉两处恒真/恒假比较（`-Wtype-limits` 不再报）。
14. RUN 页刷新 20 Hz → 10 Hz（发射时 5 Hz）。

## 2. 刷写

和官方固件一样：用官方的刷写工具进 bootloader 后写入 `f4hwn.sstv.doppler-fixed-20261027.bin`。
刷完建议先做三件事：
1. `F + 0` 进多普勒页，确认底行不再报错；
2. 用 PC 工具「自检」(0x076A) 看阶段号；
3. 长按 `MENU` 武装，确认底行显示 `ARMED`（这是本轮新加的反馈）。

## 3. 回滚

保留原机备份的 bin 即可回刷。本轮改动只涉及 App 层源码，不动 bootloader 与校准区。
